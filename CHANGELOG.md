# Changelog

## 1.2
- Offline route database (Virtual Radar Server standing data, ~620,000 callsigns, 3 MB). Routes appear
  instantly without network; adsb.lol is only asked when a callsign is missing.
- The flight card checks the aircraft is near the route on file and warns when it isn't.
- Side panel spacing fixed when a route is shown.

## 1.1
- Full-screen flight card (Y): big callsign, origin → destination, km flown / to go, ETA, live data.

## 1.0
- First release: live ADS-B globe, lock and follow, military / private / alert filters, worldwide
  emergency squawk polling, button setup. Runs on stock firmware without pygame.
